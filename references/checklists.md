# Quality Checklists

## Incident Response Report Checklist
- [ ] Executive summary states what happened, impact, and status
- [ ] Timeline is chronological and sourced
- [ ] Initial access vector identified or marked unknown with confidence
- [ ] Impact quantified where possible (records, downtime, estimated cost)
- [ ] Containment, eradication, and recovery actions documented
- [ ] Lessons learned include both what worked and what to improve
- [ ] IOCs listed with context

## CTI Report Checklist
- [ ] Central claim stated with confidence in executive summary
- [ ] Actor snapshot completed
- [ ] Techniques mapped to MITRE ATT&CK
- [ ] IOCs include role/context
- [ ] Attribution (if made) supported by multiple signals
- [ ] Defensive recommendations tied to observed techniques
- [ ] Likelihood used only for forward-looking statements

## Executive Summary Checklist
- [ ] Readable in under 5 minutes
- [ ] Contains key metrics
- [ ] Business impact clear
- [ ] Top recommendations visible
- [ ] Minimal unexplained jargon
